1. Two supplied images are now included in `assets/`: `hook.png` and `problem.png`.
2. Add the two purpose-built supporting images when they are ready, using: `solution.jpg` and `unique-mechanism.jpg`.
3. Replace `#checkout` in `index.html` with the secure Systeme checkout URL.
4. Replace the general guarantee line with the exact, source-approved guarantee wording from the offer PDF / checkout.
5. Confirm the privacy, support, emergency, testimonial, and refund language against the final product and applicable rules before running ads.

Missing images intentionally render as calm, labeled placeholders, making the file safe to review before assets are inserted.
